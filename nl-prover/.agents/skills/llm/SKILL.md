# LLM Tools

LLM-assisted tools for proof strategy and mathematical discussion. All scripts are in `cli_tools/`.

## Available Tools

| Tool | Purpose | When to use |
|------|---------|-------------|
| **discussion-partner** | Free-form discussion with Gemini or GPT via OpenRouter when available | When stuck on a proof strategy or need high-level mathematical advice |

For full parameters and examples, read the corresponding `reference-<tool>.md` file in this directory.
